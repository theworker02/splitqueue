# splitqueue

Split structured JSON queue payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/splitqueue/

## Install / run

```bash
git clone https://github.com/theworker02/splitqueue.git
cd splitqueue
node src/cli.js
node --test
```
